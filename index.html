北海道行程 詳細版

2026年10月28日 – 11月3日 · 最後更新：10月28日 17:10

住宿：札幌大通里士滿酒店
地址：札幌市中央區南2條襸4丁目4-1
電話：011-208-0055
28–31日、11月1–3日入住。31日早上 check out 後去旭川。
Day 1 · 抵達札幌 10月28日（三）
機場 → 酒店
15:00 抵達新千歲機場
JR 快速 Airport 新千歲機場 → 札幌站（約36分鐘）
票價：1,230日圓。可用 ICOCA / Kitaca / Suica。在地下1樓 JR 售票機買票或直接用 IC 卡。
札幌站 → 大通站
出 JR 閘後找「地下鉄南北線」或「チ・カ・ホ」指示，進入地鉄さっぽろ站，搭南北線往真駒內方向，坐1站到大通站（約1–2分鐘）。
大通站 → 酒店
大通站出「南改札口」（往すすきの方向）→ 進入地下街ポールタウン → 一路往南走 → 找「狸小路4・5・6・7丁目」指示 → 轉右上扶手梯到地面 → 狸小路商店街再走約1分鐘到酒店。
全程幾乎在地下，不怕下雪。總時間約50–60分鐘。
晩餐 · 拉麵
札幌ラーメン 悠（はるか）
札幌市中央區南5條襸3丁目 N・グランデビル 1F（元祖さっぽろラーメン横丁內）
營業：12:00–15:00、17:00–23:00（週日到22:00）
推薦：味噌拉麵（約900日圓）
從酒店步行約5–8分鐘，在拉麵横丁裡面。
夜間 · 中島公園紅葉點燈
點燈時間：17:00–21:00（10月23日–11月3日）
從薄野站搭南北線坐1站到「中島公園站」，出1號或3號出口即到。
銀杏並木、菖蒲池免費。日本庭園晚上收費600日圓（小學生以下免費）。
地鉄末班車約24:00，建議21:30前開始返回酒店。
Day 2 · 二條市場 + 北大 + 神宮 10月29日（四）
早上 · 二條市場
08:30–09:00 從酒店步行出發（約8–12分鐘）
穿過狸小路商店街往東走 → 過創成川 → 到二條市場
札幌市中央區南3條東1–2丁目
必吃：大磯 或 どんぶり茶屋 海鮮丼
建議三色丼或五色丼。市場多數店約7:00–17:00營業。
上午 · 北海道大學
二條市場 → 大通站（南北線）→ 北12條站（1站）→ 步行4–5分鐘到北大
票價約210日圓。建議停留1–1.5小時看銀杏大道、克拉克像。
中午 · 奧芝商店 湯咖哩
北大 → 北12條站（南北線）→ 大通站 → 轉東西線 → さっぽろ站 → 步行3–5分鐘
奧芝商店 駅前創成寺
札幌市中央區北4條襸1丁目 ホクレンビル B1F
推薦：蝦湯 + 漢堡排
下午 · 北海道神宮
奧芝商店 → さっぽろ站（東西線）→ 圓山公園站 → 出2/3號出口步行約15分鐘
神宮免費。建議停留1–1.5小時，可順便逛圓山公園。
晚上（待定）
建議選項：
1. 藻岩山纜車看夜景（來回約2,100日圓，末班上行21:30）
2. 回薄野 / 狸小路逛街 + 拉麵横丁吃拉麵
3. 輕鬆休息
Day 3 · 札幌自由活動 10月30日（五）
建議
這天仍住大通里士滿酒店。可去麵屋彩未、藻岩山、或繼續逛街。
Day 4 · 早上去旭川 10月31日（六）
早上從大通酒店 check out → JR 特急去旭川
旭川動物園 / 青池（視時間）
